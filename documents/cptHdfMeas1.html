Hausdorff測度の非アトム性の証明（前半）

今回は以下の定理Aを示そうと思います。少し長くなるので前半と後半で２つの記事に分けて、前半のこの記事では目標の定理を示すための準備をしていきます。 後半の記事はこちら。

定理A

\(n\in\N\), \(0 \leq s\leq n\) とする. \(H^s\) で \(\R^n\) 上のHausdorff測度を表すことにする. \(A\subset\R^n\) は解析集合（特にBorel集合）であるとする.
このとき, \(0 < H^s(A) \leq\infty\) ならば \(K\subset A\): コンパクト が存在して \(0 < H^s(K) < \infty\).
定理Aを認めると、次の系Bが簡単に従います。系Bで述べられている性質は非アトム性と言われ、これが成り立たない測度はアトム的と呼ばれます。

系B（Hausdorff測度の非アトム性）

\(n\in\N\), \(0 \leq s\leq n\) とする. \(H^s\) で \(\R^n\) 上のHausdorff測度を表すことにする. \(A\subset\R^n\) はBorel集合であるとする.
このとき, \(0 < H^s(A) \leq\infty\) ならば \(B\subset A\) が存在して \(0 < H^s(B) < H^s(A)\). 定理Aにより \(H^s(A) < \infty\) の場合に示せば十分です. \(\mu=H^s|_A\) が非アトム的であることを示す訳ですが, これは \(\mu\) が \(\R^n\) 上の有限測度であることと, 一点集合の測度が0になるという性質だけから一般に示すことができます. あとの詳細は演習問題とします.
ここで、後半も含め、今回の記事を通して \(n\in\N\) と \(0 \leq s \leq n\) を固定しておこうと思います。補題の主張に一々これを書くのは煩わしいですからね。 また定理Aは \(s=0,n\) のときは自明なので、\(s\ne 0,n\) であるとします。（この記事で紹介するその他の補題も \(s=0,n\) の場合は自明に真であるか自明に偽である場合がほとんどなので、困らないと思います。）
