誤植・誤りのメモ(仮置場)

p20, Example 2.9 (ii); rectifiable curve \(\Gamma\) に、例えば \(C^1\) の仮定が必要.
p22, Theorem 2.13; 主張に \(p \leq q\) の仮定が必要.
p31 line 3; " \(\widehat{\mu_\e}=\widehat{\psi_\e}\widehat{\mu}\to\widehat{\mu}\) uniformly " とあるが, 各点収束までしか言えない. 例えばδ測度の場合.
p34, equation (3.38); 右辺の \(-t^mJ_{m+1}(t)\) は, \(-t^{-m}J_{m+1}(t)\) の誤り.
p40, line 29; " If \(\mu\in\M([0,1]^n)\) with \(|\widehat\mu(z)|\lesssim|z|^{-s/2}\) for \(z\in\Z^n\) and \(\varphi\in\S(\R^n)\), then \(|\widehat{\varphi\mu}(x)|\lesssim|x|^{-s/2}\) for \(x\in\R^n\) " とあるが, 正確には \(\mu\) を周期化した測度 \(\widetilde\mu\) について \(|\widehat{\varphi\widetilde\mu}(x)|\lesssim|x|^{-s/2}\) である.
p41, Theorem 3.13; \(E\) は \(E_\a\) の誤植.
p45, equation (3.53); \(\mu(Bx,r))\) は \(\mu(B(x,r))\) の誤植.
p46, equation (3.54); \(\widetilde R=g(L^{-1}(Q_0))\) とあるが, これだと原点中心にならないので, 例えば平行移動の項を加えるなどの修正が要る.
p51, equation (3.66); \(Q_n=[0,1]^n\) として " if \(\mu,\nu\in\M(Q_n)\), then \(\widehat\mu(z)=\widehat\nu(z)\) for all \(z\in\Z^n\) implies \(\mu=\nu\) " とあるが, \(\mu=\delta_1,\ \nu=\delta_0\) が反例. 周期化 \(\M([0,1]^n)\to\M(\R^n),\mu\mapsto\sum_{z\in\Z^n}\mu(\cdot - z)\) が単射でないのが原因.
p52-53, Theorem 3.21; 証明で \(\int(g_\e*f)f=\sum_{z\in\Z^n}\widehat{g_\e}(z)|\widehat{f}(z)|^2\) とあるが, これは左辺の \(g_e\) を周期化した関数 \(G_\e=\sum_{z\in\Z^n}g_\e(\cdot - z)\) にしなくては成り立たないので, 証明にやや修正が必要.
p59, equation (4.7); " \(\d(\mu_i)\to\d(\mu)\) weakly if \(\mu_i\to\mu\) weakly " とあるが, これは誤りで, たとえば「 \(\mu_i\) たちが同じコンパクト台を持つ」などの条件が要る.
p76, equation (5.7); \(n-1\) 次球面 \(S^{n-1}\) が誤って \(\S^{n-1}\) と書かれている. その上の \(e\in\S^{n-1}\) も同様.
p77, line 3; \[\int_{\R^n}|\widehat\mu(x)|^2(1+|x|)^{t-1-\tau}dx\lesssim I_s(\mu) < \infty\] とあるが, 今Theorem 5.6 の証明をしているのであってTheorem 5.5 の証明をしているわけではないので, \(I_s(\mu) < \infty\) という仮定はない. ここは \(1-t-\tau < s-n\) と \(\dim_S\mu=s\) ということから \[\int_{\R^n}|\widehat\mu(x)|^2(1+|x|)^{t-1-\tau}dx < \infty\]が直接従う.
p77, line 16; \(\int_{|s|\leq 2^{j+2}}\) とあるのは \(\int_{|u|\leq 2^{j+2}}\) の誤り.
p78, line 14; "This can been seen ..." は "This can be seen" の誤植.
p432; T. W. Wolff とあるが, おそらくこれは T. H. Wolff の誤植.
